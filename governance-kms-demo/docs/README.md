# governance-kms-demo docs

This directory contains documentation for the governance KMS demo placeholder.

Setup
1. Create and activate a Python virtual environment:
   python3 -m venv .venv
   source .venv/bin/activate
2. Install dependencies:
   pip install -r ../requirements.txt

Run
   python3 ../app.py

Notes
- This demo is a placeholder. Update the app and docs with real details as you develop the demo.
